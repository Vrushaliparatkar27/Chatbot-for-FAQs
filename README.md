# 🤖 FAQ Chatbot using NLP & Cosine Similarity

An intelligent FAQ Chatbot designed to match user queries with the most relevant response using Natural Language Processing techniques.

## ✨ Key Features
* **Data Preprocessing:** Tokenization, lemmatization, and text cleaning using SpaCy/NLTK.
* **Vectorization & Similarity Matching:** Implemented TF-IDF / embeddings and Cosine Similarity for precise intent matching.
* **Interactive Interface:** Clean user interaction interface to query the dataset seamlessly.

## 🛠️ Tech Stack
* **Language:** Python
* **NLP Libraries:** NLTK / SpaCy, Scikit-learn
* **UI Framework:** Streamlit / Gradio / Tkinter (adjust as applicable)
